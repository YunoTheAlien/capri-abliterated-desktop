# An art strip

Art doesn't go in a `.capri-mod`. It is a `.capri-skin`: a zip of her sprite strips with a `skin.json`, the way
MODDING.md's "Stacking skins" has it.

```json
{ "format": 1, "id": "night-owl-hat", "name": "Night Owl Hat", "author": "You", "description": "A sleepy hat.", "accessory": true }
```

1. Each strip is the same size as hers. Only include the strips you draw on.
2. With `"accessory": true` it's see-through except what you add, and goes on top of whatever she wears.
3. Share it beside the pack. Both turn on and off on their own.
