# A name and wake names

```json
"names": { "name": "Owl", "wake": [ "owl", "hey owl" ] }
```

1. `wake` joins the names she answers to while the pack is on.
2. `name` is offered to Custom Names once, when the pack turns on. A name you set yourself always wins.
3. Each name is 2 to 32 letters or numbers, with single spaces, dashes or apostrophes between them.
